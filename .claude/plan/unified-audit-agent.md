# 统一交互式审计智能体 - 实施规划

## 项目概述

### 目标
将 CodeScan 系统从多个分散功能（开始扫描、调用链、代码图、变体分析、代码搜索）整合为统一的"交互式审计智能体"。智能体支持 LLM 函数调用（Function Calling）来使用各种工具，实现真正的智能化代码审计。

### 核心变更
1. **取消"开始扫描"模式** - 不再支持直接批量扫描
2. **统一智能体入口** - 所有功能通过对话式交互访问
3. **LLM 工具调用** - 智能体可自主调用分析工具
4. **简化前端导航** - 聚焦于智能审计体验

---

## 已明确的决策

- **核心架构**：扩展现有 `InteractiveAuditAgent`，整合所有分析工具
- **技术栈**：继续使用 Vue 3 + FastAPI + WebSocket
- **工具系统**：复用现有 `agent/tools/` 架构，添加新工具
- **向后兼容**：保留高级功能页面，折叠到子菜单

## 验收标准

### 功能验收
1. [ ] 用户可以通过自然语言对话完成代码审计
2. [ ] LLM 能够自主选择并调用合适的工具
3. [ ] 工具执行过程和结果可视化展示
4. [ ] 发现可以被确认/拒绝并持久化
5. [ ] 会话可以恢复和继续

### 性能验收
1. [ ] 工具调用响应时间 < 5秒（单工具）
2. [ ] 流式响应首字节时间 < 1秒
3. [ ] 会话恢复时间 < 2秒

### 用户体验验收
1. [ ] 导航结构清晰，主入口突出
2. [ ] 工具调用过程透明可见
3. [ ] 错误提示友好明确

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| LLM 工具选择不准确 | 分析效率下降 | 优化提示词，添加工具使用示例 |
| Token 超限 | 对话中断 | 实现上下文裁剪和摘要 |
| 工具执行超时 | 用户体验差 | 添加超时控制和取消机制 |
| 向后兼容问题 | 影响现有用户 | 保留高级工具入口 |
