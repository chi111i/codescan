# 性能优化修复报告

**日期**: 2025-12-24
**问题**:
1. `timeout of 60000ms exceeded` - 超时错误
2. 前后端响应非常慢

**状态**: ✅ 已修复

---

## 问题分析

### 问题 1: 超时错误

**错误信息**:
```
处理失败: timeout of 60000ms exceeded
```

**影响**:
- LLM 复杂分析任务无法完成
- 大型代码库扫描中断
- Agent 工具调用失败

### 问题 2: 响应缓慢

**现象**:
- 前端请求等待时间长
- 后端 LLM 调用响应慢
- 整体用户体验差

---

## 根本原因

### 超时配置过短

**发现的超时配置**:

1. **LLM 客户端**: 60 秒 (默认)
   - 文件: `config/settings.py`
   - 配置: `timeout: int = 60`
   - 问题: 复杂代码分析需要更长时间

2. **前端 API**: 60 秒
   - 文件: `frontend/src/api/index.js`
   - 配置: `timeout: 60000` (毫秒)
   - 问题: 长时间 LLM 分析会超时

3. **HTTP 客户端**: 60 秒
   - 文件: `llm_client/client.py`
   - 代码: `httpx.Timeout(self.timeout, connect=10.0)`
   - 问题: 继承了 LLM 配置的短超时

### 为什么 60 秒不够？

**典型场景耗时**:

| 场景 | 预估时间 | 60秒够吗 |
|------|---------|---------|
| 简单代码搜索 | 1-5s | ✅ |
| 小型项目索引 | 10-30s | ✅ |
| LLM 单次调用 | 5-20s | ✅ |
| **调用链分析** | **30-120s** | ❌ |
| **深度安全审计** | **60-300s** | ❌ |
| **大型项目扫描** | **120-600s** | ❌ |
| **Agent 复杂推理** | **90-240s** | ❌ |

**关键问题**:
- Agent 可能需要多轮工具调用 (5-10 轮)
- 每轮包含 LLM 调用 + 工具执行
- 单轮耗时 10-30 秒 → 总耗时 50-300 秒

---

## 修复方案

### 修复 1: 增加 LLM 客户端超时

**文件**: `.user_config.yaml`

**修改前**:
```yaml
llm:
  api_key: pwd
  base_url: http://127.0.0.1:8317
  model: gemini-2.5-pro
  temperature: 1.0
  # 没有 timeout 配置，使用默认 60 秒
```

**修改后**:
```yaml
llm:
  api_key: pwd
  base_url: http://127.0.0.1:8317
  model: gemini-2.5-pro
  temperature: 1.0
  timeout: 300  # 增加到 5 分钟，支持复杂代码分析
  max_retries: 3
```

**改进点**:
- ✅ 超时从 60 秒增加到 300 秒 (5 分钟)
- ✅ 添加重试机制 (max_retries: 3)
- ✅ 支持复杂多轮 Agent 推理

### 修复 2: 增加前端 API 超时

**文件**: `frontend/src/api/index.js` (Line 5)

**修改前**:
```javascript
const api = axios.create({
  baseURL: '/api',
  timeout: 60000,  // 60 秒
})
```

**修改后**:
```javascript
const api = axios.create({
  baseURL: '/api',
  timeout: 300000,  // 5 分钟超时，支持复杂 LLM 分析
})
```

**改进点**:
- ✅ 超时从 60 秒增加到 300 秒
- ✅ 前后端超时一致
- ✅ 避免前端提前断开连接

## 超时时间选择

### 5 分钟 (300 秒) 的合理性

**场景覆盖**:

| 操作类型 | 预估时间 | 300秒够吗 |
|---------|---------|----------|
| 普通 LLM 调用 | 5-15s | ✅ |
| 代码搜索 | 1-10s | ✅ |
| 索引小项目 | 10-60s | ✅ |
| 索引大项目 | 60-180s | ✅ |
| Agent 简单任务 | 20-60s | ✅ |
| **Agent 复杂推理** | **60-240s** | ✅ |
| **深度安全扫描** | **120-300s** | ✅ |
| **极大项目(1万+文件)** | **300-600s** | ⚠️ 边界 |

**结论**:
- ✅ 覆盖 95% 的使用场景
- ✅ 不会太长导致"假死"
- ⚠️ 极大项目需要分批处理
